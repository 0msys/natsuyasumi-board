# なつやすみボード仕様書

## 目的

この仕様書は、現行実装の挙動を改造とテストの基準として残すものです。
画面から機能を探し、リンク先で条件・結果・例外を確認できます。

## 対象

- 子どもが毎日使うボード
- 保護者が設定を管理する画面
- lite 版と Docker 版に共通するルールと版ごとの差

API や JSON の全項目は扱いません。JSON の形式は [定義データの JSON 形式](../definition-format.md)を参照してください。

## 読み方

画面の機能一覧から、知りたい機能の詳細ページへ進みます。
各詳細ページの「テスト観点」は、最低限確認する振る舞いを示します。

仕様にない挙動を見つけた場合は、コードだけを変更せず、この仕様書も更新します。
仕様と実装が異なる場合は、現行コードとテストで再確認して差を解消します。
