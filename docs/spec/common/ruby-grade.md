# ルビと学年別漢字

## 目的

子どもの学年で未習の漢字を避けながら、必要な漢字には読みを表示します。

## ルビ記法

表示ラベルは `漢字《よみ》` の形式で記述できます。

例: `音読《おんどく》カードに書《か》く`

`《》` は直前に連続する漢字へ付きます。
対象範囲を明示する場合は `｜` を使います。
入力画面では表示結果をプレビューします。

## 学年別表示

- 学年は小1から小6です。
- 学年までに習う漢字はそのまま表示できます。
- それ以外の漢字にはルビを付けるか、ひらがなを使います。
- 標準テンプレートと画面文言は、選んだ学年に合わせて漢字を開きます。
- 子どもの名前に使う漢字は警告対象から除外します。

## 入力時の検査

管理画面は、ラベル、メモ欄、選択肢、景品、外出名などを検査します。
配当外漢字は警告であり、保存禁止にはしません。
対応しない括弧や基底のない `《》` は文字として残し、入力全体を壊しません。

## 音声

読み上げ時はルビの読みを使い、記法の括弧を発話しません。
子どものよみがなは呼びかけに使います。

## テスト観点

- 漢字1文字、連続漢字、文章中の複数ルビ
- `｜` による対象範囲指定
- 学年境界の漢字
- 子どもの名前に含まれる漢字の除外
- 配当外漢字が警告で保存可能なこと
- 対応しない括弧を文字として表示すること
- 画面表示と音声用テキストから記法を除くこと
- Python と TypeScript の結果一致
