# エラー表示と管理機能の保護

## 子どもページ

- 初期状態を取得できない場合は、再読込を促す固定文を表示します。
- 操作失敗は子ども向けの短い文へ変換して表示します。
- 記録の操作と音声読み上げの失敗は6秒後に消します。コメント読み上げと「きょうやること」読み上げの失敗も同じ扱いです。
- 画面全体の60秒更新が失敗した場合は表示せず、直前の状態を保ちます。
- テレビタイマーの失敗は6秒では消しません。5秒更新の失敗では直前の状態を保ち、取得エラーをオーバーレイ内に表示します。開始・停止の失敗も、状態を変えずにオーバーレイ内へ表示します。
- テレビタイマーのエラーは、次のタイマー通信が成功するまで表示します。5秒更新が成功すれば6秒より早く消え、通信が戻らない間は表示が残ります。
- テレビタイマーのエラーはオーバーレイを開いている間だけ見えます。閉じても状態は残り、成功前に開き直すと再び表示します。
- 子どもを切り替えると、前の子どものエラーを消します。記録の操作エラーとテレビタイマーのエラーの両方が対象です。
- 切り替え前の操作結果や音声エラーは、切り替え後に表示しません。

## 管理画面

- セッション取得失敗、一覧取得失敗、定義取得失敗を区別します。
- HTTP ステータスを取得できる読み込みエラーでは番号を併記します。
- 404 は対象定義がないことを表示します。
- 入力検証エラーは該当タブへ関連付けます。
- 保存競合は通常エラーと分け、読み直し操作を表示します。
- インポート、エクスポート、名前変更、削除の失敗は一覧上部へ表示します。

## 検証エラーと警告

- エラー: 保存できません。必須、型、日付順、キー重複、数値範囲、ランク平均点の同点などです。
- 警告: 保存できます。配当外漢字、期間中の項目変更、記録済み項目の削除などです。
- lite 版だけ、記録キーの区切り文字を含む名前・項目キーをインポート時に422、名前変更時に400で拒否します。[保存方式と版の違い](storage-variants.md#lite-版だけの検証)を参照します。

## 管理機能の保護

- Docker 版の管理 API は、設定なしでは拒否するフェイルクローズです。
- PIN は簡易ゲートであり、利用者認証ではありません。
- Docker 版は家庭内 LAN 専用です。インターネットへ直接公開しません。
- 家の外から使う場合は VPN を利用します。
- lite 版はサーバがないため、端末側のロック機能を使います。

## 削除と復元性

- 定義削除では記録を物理削除しません。
- 端末全体の復元は全置換の確認を必須にします。
- 定義にない孤立記録の物理削除は、管理 API の明示操作だけで行います。
- 残す記録は、その子どもの全年度の定義から集めたキーで判断します。
- 1年度でも定義を読み取れない場合は、孤立記録を削除せず中止します。
- 仕様書が扱う通常画面には、孤立記録の物理削除ボタンはありません。

## テスト観点

- 初期読込、操作、画面全体更新、テレビタイマー更新、テレビタイマー操作の失敗表示差
- 記録の操作と音声読み上げのエラーは6秒で消え、テレビタイマーのエラーは残ること
- テレビタイマーのエラーが次の通信成功で消え、5秒更新の成功なら6秒より早く消えること
- 子ども切り替え後に古いエラーを出さないこと
- 404、競合、検証失敗、一般通信失敗の表示差
- エラーでは保存不可、警告では保存可能なこと
- 管理設定なしで API と UI を開放しないこと
- 定義削除で記録を物理削除しないこと
- 孤立記録の判定に全年度のキーを使うこと
- 壊れた年度がある場合に孤立記録を削除しないこと
