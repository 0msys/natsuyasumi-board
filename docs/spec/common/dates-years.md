# 日付・期間・年度

## 日付

サービス上の「今日」は日本時間の日付です。
画面と保存データの日付は `YYYY-MM-DD` で扱います。
子どもページの今日表示は60秒ごとに更新します。
日付変更から次の更新までは、チェックとメモを前日へ記録します。

夏休み期間は初日と最終日を含みます。
定義は `初日 < 最終日 < 始業式` の順にします。

## 期間内外の表示

期間内は、今日のチェック、コメント、チャレンジ、テレビタイマーを表示します。
期間外でも、全期間の履歴、宿題進捗、ごほうび、新学期準備を表示します。

未来日の記録は書き込めません。
過去日は夏休み期間内なら修正できます。

## 表示する年度

同じ子どもに複数年度がある場合は、今日を基準に次の順で1件を選びます。

1. 今日を夏休み期間に含む年度
2. 終了済みのうち、終了日が最も新しい年度
3. 開始前のうち、開始日が最も近い年度
4. 期間を読めない定義しかない場合は、年度番号が最大の定義

URL の `child` は子どもだけを指定し、年度はこの規則で決めます。
編集画面では `year` クエリで年度を明示できます。

## 外出日

- 外出予定は開始日と終了日を含みます。
- 複数予定が重なる場合は、定義順で最初の名称を使います。
- 外出日は案内と履歴表示を変えますが、入力を禁止しません。
- 外出日の未達・未記入は連続満点を切りません。

## 期間限定の生活習慣

- 毎日: 期間中の全日を対象にします。
- はじめとおわりだけ: 初日からn日間と、最終日までのn日間を対象にします。
- 指定期間: 設定した開始日から終了日までを対象にします。

境界日は対象に含みます。

## テスト観点

- 日本時間の日付変更から次の60秒更新までの表示と記録日
- 初日、最終日、始業式の境界
- 現在、過去、未来の年度選択順
- 壊れた年度を含む選択
- 外出期間の初日、最終日、予定重複
- 期間端n日と指定期間の境界
