# 子どもページ

## 目的

夏休み中の生活習慣と宿題を記録し、進み具合とごほうびを確認する画面です。

## 表示と遷移

- 定義がない場合は新規作成画面へ移動します。
- 複数の子どもがいる場合は、URL の `child` と上部の名前で切り替えます。
- 指定した子どもが見つからない場合は、最初の有効な子どもを表示します。
- 有効な定義が1件もない場合は設定一覧へ移動します。
- 歯車から設定一覧へ移動します。lite 版でバックアップが必要な場合は歯車に印が付きます。

## 画面状態

- 期間外でも、宿題進捗、ごほうび、履歴、新学期準備は確認できます。
- 期間外では、今日のチェック、コメント、チャレンジ、テレビタイマーを表示しません。
- 今日が外出期間内なら、責める表現を使わず外出名を案内します。
- 初期データを読めない場合は再読込を促し、空の新規状態とは扱いません。
