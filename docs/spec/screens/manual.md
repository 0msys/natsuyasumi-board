# マニュアル

## 目的

保護者が画面の使いかたを読むための操作マニュアルです。
アプリの中に持ち、UI から直接開けます。デプロイや構築の手順は扱いません。

想定する読み手は IT に詳しくない保護者です。
子ども向け画面の説明も含みますが、文章そのものは保護者向けで、ルビと学年別漢字は適用しません。

## 表示と遷移

- URL は `/manual` です。
- 子どもページ、設定一覧、新規作成、子ども設定編集の4画面のヘッダーから開けます。
- 入口はすべて `つかいかた` というアクセシブル名を持ちます。子どもページだけアイコンのみで表示します。
- 未保存の入力を抱える2画面（新規作成、子ども設定編集）からは別のタブで開きます。
  新規作成の入力は画面内に持つだけで離脱ガードがなく、同じタブで移動すると入力を失います。
  子ども設定編集は離脱ガードで失いませんが、同じタブでは確認を挟むため読むか直すかの二択になります。
  入力を持たない2画面（子どもページ、設定一覧）は同じタブで移動します。
- lite 版では実ファイルとして事前生成します。Service Worker の任意キャッシュへ入るため、インストール後はオフラインでも開けます。
- 定義や記録を読みません。api を呼ばないため、認証も接続も不要です。

## 機能一覧

| ID | 機能 | 概要 | 表示条件 |
|---|---|---|---|
| MAN-01 | 版の切り替え | lite 版と docker 版の説明を切り替える | 常時 |
| MAN-02 | もくじ | 各節へのページ内リンクを並べる | 常時 |
| MAN-03 | 本文 | 8つの節を展開したまま並べる | 常時 |
| MAN-04 | こまったときは | よくある質問を折りたたみで並べる | 常時 |

## 版の切り替え

- 既定は、いま動いている版です。ビルド時の `__NYB_LITE__` から決めます。
- 読み手が押せば、もう一方の版の説明も読めます。
- 選んだ版は保存しません。次に開くと、また動作中の版から始まります。
- 版で異なる箇所は、その場で本文を差し替えます。差し替えた箇所には版名の帯を付けます。
- 差し替えは表示の切り替えではなく描画の有無で行います。選んでいない版の文章は DOM に残りません。
- ラジオグループとして実装します。対応する `tabpanel` を持たないため、ARIA のタブにはしません。

## 節の構成

| 節 | 版で変わる主な内容 |
|---|---|
| このアプリでできること | 記録の置き場所、使える端末の台数 |
| さいしょの準備（子どもを登録する） | ホーム画面への追加、保存領域の警告（lite）、PIN（Docker） |
| 毎日つかう画面 — 今日の記録 | 読み上げ、60秒更新で反映される範囲 |
| 進みぐあいとごほうびを見る | テレビタイマーを別端末から見られるか |
| 前の日の記録を直す | なし（両版で同じ） |
| 設定を変える | PIN、バックアップのカード、保存領域の警告、声の選択、保存競合の理由 |
| データの保存とバックアップ | 節のほぼ全体 |
| こまったときは | 接続エラー、読み上げ、鍵、記録の復旧 |

版ごとの差の内容は[保存方式と版の違い](../common/storage-variants.md)を上流とします。
版の挙動を変えるときは、その文書とこの画面の本文もあわせて直します。

版に依らない要点として、次の点を本文へ明記します。いずれも登録直後の保護者が最初につまずくところです。

- 夏休みが始まる前に登録した場合は、今日のチェックを表示せず、期間終了の文言が出ること。
- 画面に出る年度は日付から自動で決まり、選べないこと。選択順は[日付・期間・年度](../common/dates-years.md)に従います。
- 空テンプレートで作った直後は生活習慣と毎日の宿題が両方とも空で、点数が0点から動かないこと。
  空区分の警告は片方だけが空のときに出るため、この状態では出ません（[採点とランク](../common/scoring.md)）。

## 文言の出どころ

子どもページのボタン名と見出しは `backend/app/summer/ui_text.py` の生成物から引きます。
手で書き写すと `ui_text.py` の変更で黙ってずれるためです。
引くときはルビ注記だけを落とし、漢字表記のまま表示します。読みへ畳みません。

子どもの画面は学年に応じて漢字がひらがなへ開くため、実際の表示はマニュアルより かな寄り になります。
その断りを本文の冒頭に置きます。

管理画面の文言は生成物を持たないため、本文へ直接書きます。

## テスト観点

- もくじのリンクと、描かれている節が同数・同順で対応すること
- 節の見出しが、もくじの文字と一致すること
- 既定の版が、動作中の版になること
- 版を切り替えると、選んでいない版の文章が DOM から消えること
- 版の切り替えがラジオグループとして読まれること
- 4画面すべてのヘッダーに入口が残っていること
- 新規作成と子ども設定編集の入口だけが別タブで開くこと
- 新規作成の途中でマニュアルを開いても、入力が残ること
- 子どもページの入口がアクセシブル名を持つこと
- 引用した画面文言が空にならないこと（生成物のキー改名の検出）
- 引用した画面文言にルビ注記と差し込みが残らないこと
- lite 版で `/manual` が事前生成され、オフラインでも開けること
- 表示年度の説明が[日付・期間・年度](../common/dates-years.md)の選択順（期間中→終了済み→開始前）と一致すること
