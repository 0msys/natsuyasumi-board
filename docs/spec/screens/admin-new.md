# 新規作成

## 目的

子どもと夏休み期間の基本情報を4段階で登録します。
定義が1件もない場合は、子どもページから自動で移動します。

## 機能一覧

| ID | 機能 | 概要 | 表示条件 | 詳細 |
|---|---|---|---|---|
| NEW-01 | 管理画面を開く | PIN または運用設定を確認する | 画面表示時 | [管理画面へのアクセス](../features/admin-access.md) |
| NEW-02 | 名前入力 | 記録キーとなる名前と、表示・音声用のよみがなを入力する | ステップ1 | [新規作成](../features/admin-create.md) |
| NEW-03 | 学年選択 | 小1から小6を選ぶ | ステップ2 | [新規作成](../features/admin-create.md) |
| NEW-04 | 期間入力 | 初日、最終日、始業式を入力する | ステップ3 | [新規作成](../features/admin-create.md) |
| NEW-05 | テンプレート選択 | 標準または空の定義を選ぶ | ステップ4 | [新規作成](../features/admin-create.md) |
| NEW-06 | 作成 | 入力内容から定義を作り、編集画面へ移動する | 全項目が有効 | [新規作成](../features/admin-create.md) |
| NEW-07 | 前後移動 | 入力を保ったまま前後のステップへ移動する | ウィザード表示中 | [新規作成](../features/admin-create.md) |
| NEW-08 | エラー表示 | 日付順や作成処理のエラーを表示する | 入力・作成エラー時 | [エラー表示](../common/errors-security.md) |
| NEW-09 | 未保存警告 | 入力を残したままの画面離脱前に確認する | 入力が1つでもあるとき | [新規作成](../features/admin-create.md) |

## 入力の概要

- 名前は必須です。よみがなが空なら名前を使います。
- 学年は必須です。
- 日付は「初日 < 最終日 < 始業式」の順にします。
- 年度は初日の西暦から自動で決まります。
