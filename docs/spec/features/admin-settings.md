# 設定項目

## 基本と音声

- よみがな: 子どもページの呼びかけと読み上げに使います。
- 学年: 小1から小6を選びます。
- 夏休み期間: 初日と最終日を設定します。
- 始業式: 夏休み最終日より後の日を設定します。
- 音声: VOICEVOX のキャラクターと話し方を選びます。
- 試し聞き: 固定文を再生します。話者を直接指定するのは、いま表示している話者一覧から選べている場合だけです。

VOICEVOX が停止している場合は利用不可を案内します。
話者一覧だけ取得できない場合は、VOICEVOX 停止とは断定しません。

未設定の場合、話者一覧を取得できない場合、設定の話者が一覧にない場合は、試し聞きで話者を指定しません。
このときサーバは既定話者を起点に解決します。既定話者が一覧にないときは一覧の先頭の話者になります。
画面に出ている話者名と、実際に鳴る声が一致しないことがあります。

一覧にない話者IDを試し聞きでそのまま送ると400になるため、指定せずサーバの解決に任せています。
一覧を取得できている場合、子どもページは同じ話者IDを実在する話者へ落として鳴らします。落とし先の順序は[採点・コメント・音声](score-comment-speech.md#音声読み上げ)に書きます。

## 生活習慣とテレビタイマー

- 生活習慣のラベルを追加、削除、並べ替えできます。
- 「はじめとおわりだけ」を有効にすると、期間端だけ表示します。
- 中止可能を有効にすると、子どもページで「中止」を選べます。
- 対象期間を限定する開始日と終了日を設定できます。
- 期間端だけの日数は全対象習慣で共通です。
- テレビタイマーの上限を分単位で設定します。

## 毎日の宿題とメモ欄

- 毎日の宿題ラベルを追加、削除できます。
- 宿題ごとに複数のメモ欄を追加できます。
- メモ欄の種類は文字列、選択肢、時間です。
- すべてのメモ欄にラベルを設定できます。
- 文字列型だけ入力案内を設定できます。
- 選択肢にはキーと表示ラベルを設定します。
- メモ欄のキーは、同じ宿題の中で重複できません。
- 種類を変えても、選択肢など元の種類の設定値を保持します。

## チャレンジとごほうび

- チャレンジには表示ラベルを設定します。
- 1件の得点は25点で固定です。
- ごほうびにはランク名、1日平均点、任意の景品を設定します。
- 到達点は平均点と期間日数から自動計算します。
- ランクは平均点が厳密に増える順に設定します。同じ平均点は保存できません。

## 一回ものと選択宿題

- 一回ものは完了型または冊数型を選びます。
- 冊数型には目標数を設定します。1以上の整数であることだけを検証し、上限は検証しません。
- 記録できる冊数は0から99です。目標数を100以上にした定義は保存できますが、完了に到達できません。
- 種類を変えても冊数型の目標数を保持します。
- 完了型は、必要に応じて「やる・やらない」の事前判断を有効にします。
- 子どもが「やらない」にした完了型を「かならずやる」へ変えると、その項目は操作できなくなります（[宿題進捗](homework-progress.md#やらないを残したまま必須へ変えた場合)）。
- 冊数型で「かならずやる」を外しても、事前判断は表示しません。
- 選択宿題はグループ名と最低必要数を設定します。
- グループへ選択肢を追加し、任意でカテゴリを付けます。
- 最低必要数は選択肢数を超えられません。

## 新学期と外出

- 新学期準備にはラベルと期限を設定します。
- 外出には名称、開始日、終了日を設定します。
- 外出の開始日は終了日以前にします。
- 外出予定は複数登録できます。

## 共通入力規則

- 表示ラベルは空にできません。
- 生活習慣、毎日の宿題、チャレンジのキーは互いに重複できません。
- 一回もの、新学期準備、選択宿題の記録キーも互いに重複できません。
- ごほうびランクのキーはランク内で重複できません。
- 新規項目のキーは保存時に自動採番できます。
- ルビ記法と学年別漢字の扱いは[ルビと学年別漢字](../common/ruby-grade.md)に従います。
- 採点不能な空カテゴリなど、利用はできても意図確認が必要な状態は警告にします。

## テスト観点

- 各タブの追加、編集、削除
- 生活習慣の並べ替え
- 任意の完了型だけに事前判断を表示すること
- 文字列型のメモ欄だけに入力案内を表示すること
- 種類を戻したときに元の種類の設定値を復元すること
- キー、ラベル、日付、数値範囲の検証
- VOICEVOX の停止と一覧取得失敗の表示差
- 一覧から選んだ話者では試し聞きがその話者で鳴ること
- 一覧を取得できない場合と、一覧にない話者IDの場合は、試し聞きが話者を指定せず、サーバの解決した話者で鳴ること
- 既定話者が一覧にない場合、試し聞きが一覧の先頭の話者で鳴ること
- 平均点と期間変更によるランク到達点の再計算
- 選択宿題の最低必要数境界
- 外出期間の正順
- 警告と保存禁止エラーの区別
