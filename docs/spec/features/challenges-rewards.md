# チャレンジとごほうび

## スペシャルチャレンジ

その日の基本点が100点になると操作できます。
基本点が100点未満の間は、項目を表示してもロックします。

- 項目ごとに「できた」を切り替えます。
- 1項目につき25点を加算します。
- 基本点が100点未満へ戻ると、記録が残っていてもボーナスへ加算しません。
  記録は残したままロックするため、消すには基本点をいったん100点へ戻します。
- その日の最大点は `100 + 項目数 × 25` です。画面の案内文にもこの値を出します。
  採点区分が空でボーナスが付かない場合は、[採点とランク](../common/scoring.md#ボーナス)のとおり
  最大点が下がり、案内文もその値になります。
- 過去日の修正モーダルからも、同じ条件で記録・解除できます（[履歴と過去日修正](history-edit.md#過去日の修正)）。

## ごほうびグラフ

夏休み全体の累計点と、ランクの到達状況を表示します。

- ランクは設定順に表示します。
- 各ランクの到達点は、設定した1日平均点と期間日数から計算します。
- 合計点が到達点以上のランクのうち、最も高いものを到達済みとします。
- 次のランクまでの残りをグラフで確認できます。
- ランクに景品が設定されている場合は併記します。
- 到達点が1日の最大点の合計を超える場合も、縦軸の上端を到達点まで伸ばして描きます。

## 制約

- ランクの平均点は厳密な昇順に設定します。同じ平均点は保存できません。
- ランクの平均点は1日の最大点以下に設定します。超えた場合は保存できますが警告します。
- 初回ウィザードのテンプレートも、そのチャレンジ項目数で到達できる平均点にします。
- ランクキーは重複できません。
- ごほうび設定が空の場合、グラフを表示しません。
- 過去日の修正も累計点とランクへ反映します。

## テスト観点

- 基本点99点と100点でのロック切り替え
- チャレンジ1件ごとの25点加算
- 案内文の最大点が項目数に追従すること
- 基本点を100点未満へ戻した場合のボーナス除外
- 過去日モーダルでのロック切り替えと記録・解除
- 期間日数を含むランク到達点の計算
- ランク境界の直前、同点、直後
- 平均点が1日の最大点と同じ場合と超えた場合の警告有無
- チャレンジ項目を減らした場合と、採点区分が空で最大点が下がった場合の警告
- 到達点が1日の最大点の合計を超える場合のグラフ描画（帯・ラベル・ペース線が枠内に収まること）
- 過去日修正による累計点とランクの再計算
- ごほうび未設定時にグラフを表示しないこと
