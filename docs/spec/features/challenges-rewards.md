# チャレンジとごほうび

## スペシャルチャレンジ

その日の毎日の宿題をすべて達成すると操作できます。生活習慣は解放条件に含めません。
未達成の宿題が1件でも残っている間は、項目を表示してもロックします。
毎日の宿題が0件の定義では解放しません。

解放と加点は別の条件です。夜だけ記録できる生活習慣があると、宿題を終えても
就寝前まで操作できなくなるため、解放は宿題だけで判定します。
一方で生活習慣を落とした日に加点しないよう、加点は基本点100点のままにします。

- 項目ごとに「できた」を切り替えます。
- 1項目につき25点を加算します。加点するのは基本点が100点の日だけです。
- 解放されていても基本点が100点未満の間は加点しません。
  この間は、達成済みのチャレンジ1件につき25点を保留額として案内文に出します。
  保留額は達成件数から求めます。1件も達成していなければ0点なので、案内文を出しません
  （受け取れない点数を約束しないため）。
- 生活習慣が「やらなかった」または未記入のまま終わった日は、記録が残っていても
  ボーナスへ加算しません。記録は残るため、基本点を100点へ戻せば加算されます。
- 宿題を未達成へ戻すと、記録を残したまま再びロックします。
- その日の最大点は `100 + 項目数 × 25` です。画面の案内文にもこの値を出します。
  採点区分が空でボーナスが付かない場合は、[採点とランク](../common/scoring.md#ボーナス)のとおり
  最大点が下がり、案内文もその値になります。
- 過去日の修正モーダルからも、同じ条件で記録・解除できます（[履歴と過去日修正](history-edit.md#過去日の修正)）。

## ごほうびグラフ

夏休み全体の累計点と、ランクの到達状況を表示します。

- ランクは設定順に表示します。
- 各ランクの到達点は、設定した1日平均点と期間日数から計算します。
- 合計点が到達点以上のランクのうち、最も高いものを到達済みとします。
- 次のランクまでの残りをグラフで確認できます。
- ランクに景品が設定されている場合は併記します。
- 到達点が1日の最大点の合計を超える場合も、縦軸の上端を到達点まで伸ばして描きます。

## 制約

- ランクの平均点は厳密な昇順に設定します。同じ平均点は保存できません。
- ランクの平均点は1日の最大点以下に設定します。超えた場合は保存できますが警告します。
- 初回ウィザードのテンプレートも、そのチャレンジ項目数で到達できる平均点にします。
- ランクキーは重複できません。
- ごほうび設定が空の場合、グラフを表示しません。
- 過去日の修正も累計点とランクへ反映します。

## テスト観点

- 毎日の宿題の未達成1件ありと全件達成でのロック切り替え
- 生活習慣が未記入でも、宿題を全件達成すれば解放されること
- 毎日の宿題が0件の定義では解放しないこと
- 基本点99点と100点での加点切り替え（解放したままの加点保留）
- 加点が保留されている間の案内文（達成0件では出さない・達成件数に応じた保留額）
- チャレンジ1件ごとの25点加算
- 案内文の最大点が項目数に追従すること
- 基本点を100点未満へ戻した場合のボーナス除外
- 過去日モーダルでのロック切り替えと記録・解除
- 期間日数を含むランク到達点の計算
- ランク境界の直前、同点、直後
- 平均点が1日の最大点と同じ場合と超えた場合の警告有無
- チャレンジ項目を減らした場合と、採点区分が空で最大点が下がった場合の警告
- 到達点が1日の最大点の合計を超える場合のグラフ描画（帯・ラベル・ペース線が枠内に収まること）
- 過去日修正による累計点とランクの再計算
- ごほうび未設定時にグラフを表示しないこと
