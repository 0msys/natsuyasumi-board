# 編集・検証・保存

## 編集単位

表示中の子ども・年度の定義全体を1つのドラフトとして扱います。
タブ切り替えではドラフトを破棄しません。
いずれかの項目を変更すると「保存していない変更があります」と表示します。

## 項目の追加と削除

- 一覧形式の設定は追加、削除ができます。
- 並べ替えができるのは生活習慣だけです。
- 選択式宿題以外で、記録に使われた項目を削除する場合は、記録件数を示して確認します。
- 選択式宿題の選択肢とグループは、記録があっても削除確認を表示しません。
- 定義から項目を削除しても、既存の記録は自動削除しません。
- 夏休み期間中に生活習慣または毎日の宿題を追加すると、過去日の点数が下がり得ることを警告します。
- 記録のある項目を削除すると、過去日の点数が上がり得ることを警告します。選択式宿題は対象外です。
- 記録のない生活習慣または毎日の宿題の削除では、点数が上がり得る場合も警告しません。
- 生活習慣または毎日の宿題が空の場合は、その区分ごとに基本点100点へ届かないことを警告します。
  両方空の場合は2件警告します。詳細は[採点とランク](../common/scoring.md)を参照します。
- ごほうびの1日平均点が1日の最大点を超える場合は、そのランクへ到達できないことを警告します。
  スペシャルチャレンジを減らして到達不能になった場合も同様です。

## 保存処理

編集画面を開いた時点でも、保存せずに定義全体を一度検証し、既存のエラーと警告を表示します。
検証に失敗した場合は表示せず、画面の操作も妨げません。
未保存の変更として扱わないため、この時点では保存操作を行えません。

保存時の手順は次のとおりです。

1. 編集中の定義全体をサーバまたは端末内の検証処理へ送ります。
2. エラーがあれば保存を中止します。
3. 警告だけなら保存できます。
4. 検証済みの定義を revision 付きで保存します。
5. 成功時は採番済みキーと新しい revision でドラフトを置き換えます。

エラーと警告は内容を一覧し、該当タブに件数を表示します。
全体に関する問題は特定タブへ割り当てません。

## 保存競合

取得時の revision と保存時の revision が異なる場合は保存しません。
「ほかの画面で変更されています」と表示し、読み直し操作を出します。
読み直すと表示中年度のサーバ内容で未保存のドラフトを置き換えます。

## 画面移動

- 同じ年度内のタブ切り替えでは警告しません。
- 年度切り替え、別画面への移動、ブラウザを閉じる操作では未保存確認を出します。
- 確認を取り消した場合はドラフトと表示位置を保ちます。

## 年度削除

「この年をけす」は複数年度がある場合だけ表示し、表示中年度だけを削除します。
削除後は、残った年度のうち最も新しい年度へ移動します。
子どもの全年を削除する操作は設定一覧にだけ置きます。

## テスト観点

- タブをまたいだドラフト保持
- 保存前でも、画面を開いた時点で既存の警告が出ること
- 空区分の警告が区分ごとに出ること。両方空の場合に2件出ること
- エラー時の保存中止とタブ別件数
- 警告だけの場合の保存成功
- 保存後の revision と自動採番キー
- 競合時に上書きせず、読み直せること
- 同年度タブと、年度変更・画面離脱の警告差
- 選択式宿題以外の使用中項目で削除確認を表示すること
- 使用中の選択式宿題を確認なしで削除し、既存記録を残すこと
- 期間中の生活習慣・毎日の宿題の追加警告
- 未記録の生活習慣・毎日の宿題の削除では警告しないこと
- 単年度削除後に残った最新年度へ移動すること
