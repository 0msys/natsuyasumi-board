# 新規作成

## 手順

### 1. 名前とよみがな

- 名前は必須です。
- よみがなは任意です。空の場合は名前を使います。
- 名前は子どもの識別と記録の保存キーに使います。
- よみがなは子どもページの呼びかけと読み上げに使います。

### 2. 学年

小1から小6を1つ選びます。
学年は標準ラベルの漢字表記、入力中の漢字警告、コメントの口調に使います。

### 3. 期間

夏休みの初日、最終日、始業式を入力します。
順序は `初日 < 最終日 < 始業式` とします。
年度は初日の西暦から自動で決めます。

### 4. テンプレート

- 標準: 代表的な生活習慣、宿題、ごほうびを学年向けの表記で作ります。
  ごほうびの平均点は、そのチャレンジ項目数で到達できる範囲に収めます。
- 空: 項目なしの最小定義を作ります。

標準テンプレートを選んでも、作成後にすべて編集できます。

## 画面操作

- 現在位置を「ステップ n / 4」で表示します。
- 現在ステップの必須入力を満たすまで「つぎへ」を無効にします。
- 「もどる」で前ステップへ戻っても入力内容を保持します。
- 作成中は二重送信を禁止します。
- 成功後は作成した子どもの編集画面へ、年度指定なしで移動します。
- 既存の子どもへ別年度を作成した場合は日付に応じた年度が開き、作成した年度が開くとは限りません。
- 失敗時はステップ4に理由を表示し、入力内容を保持します。

## 画面移動

入力内容は作成するまで画面内にしか持ちません。移動すると失われます。

- 入力が1つでもある状態で画面を離れるときは確認します。ブラウザを閉じる操作も同じです。
- 確認を取り消した場合は入力と表示中ステップを保ちます。
- 入力の判定は、名前、よみがな、学年、3つの日付のいずれかが空でないことです。
  テンプレートは既定値があるため数えません。
- 何も入力していない場合は確認しません。
- 作成に成功して編集画面へ移動するときは確認しません。確認を省くのはその移動先だけです。
  作成後に移動が起きずこの画面へ残った場合は、以降の離脱でまた確認します。

## 制約

- 同じ子ども名・同じ年度は作成できません。
- 空白だけの名前は作成できません。
- 初日と最終日を同日にできません。
- 最終日と始業式を同日にできません。

## テスト観点

- 各ステップの必須入力とボタン活性
- よみがな未入力時の名前利用
- 日付の正順、同日、逆順
- 初日からの年度導出
- 標準と空テンプレートの内容
- 作成直後の定義が検証を警告なしで通ること（ごほうびが到達可能であること）
- 二重送信防止
- 作成失敗後の入力保持と再実行
- 新しい子どもの作成成功後に作成年度の編集画面が開くこと
- 既存の子どもへ別年度を作成した場合に、日付に応じた年度の編集画面が開くこと
- 入力がある状態の離脱で確認が出て、取り消すと移動しないこと
- 未入力の離脱では確認が出ないこと
- 作成に成功した移動では確認が出ないこと
