# 新規作成

## 手順

### 1. 名前とよみがな

- 名前は必須です。
- よみがなは任意です。空の場合は名前を使います。
- 名前は子どもの識別と記録の保存キーに使います。
- よみがなは子どもページの呼びかけと読み上げに使います。

### 2. 学年

小1から小6を1つ選びます。
学年は標準ラベルの漢字表記、入力中の漢字警告、コメントの口調に使います。

### 3. 期間

夏休みの初日、最終日、始業式を入力します。
順序は `初日 < 最終日 < 始業式` とします。
年度は初日の西暦から自動で決めます。

### 4. テンプレート

- 標準: 代表的な生活習慣、宿題、ごほうびを学年向けの表記で作ります。
- 空: 項目なしの最小定義を作ります。

標準テンプレートを選んでも、作成後にすべて編集できます。

## 画面操作

- 現在位置を「ステップ n / 4」で表示します。
- 現在ステップの必須入力を満たすまで「つぎへ」を無効にします。
- 「もどる」で前ステップへ戻っても入力内容を保持します。
- 作成中は二重送信を禁止します。
- 成功後は作成した子どもの編集画面へ移動します。
- 失敗時はステップ4に理由を表示し、入力内容を保持します。

## 制約

- 同じ子ども名・同じ年度は作成できません。
- 空白だけの名前は作成できません。
- 初日と最終日を同日にできません。
- 最終日と始業式を同日にできません。

## テスト観点

- 各ステップの必須入力とボタン活性
- よみがな未入力時の名前利用
- 日付の正順、同日、逆順
- 初日からの年度導出
- 標準と空テンプレートの内容
- 二重送信防止
- 作成失敗後の入力保持と再実行
- 作成成功後の遷移先
