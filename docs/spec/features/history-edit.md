# 履歴と過去日修正

## 履歴表示

夏休みの初日から最終日までを日ごと、項目ごとに表示します。

- 生活習慣と毎日の宿題の状態を記号で表示します。
- 基本点とチャレンジ込みの合計点を日ごとに表示します。
- 満点の連続日数を表示します。
- 外出日は外出名と専用表示を付けます。
- 今日より未来の日は記録操作の対象にしません。

## 日付の確認

日付を押すとモーダルを開きます。
過去日は閲覧表示で開き、「なおす」を押すと編集できます。
当日は最初から編集でき、「なおす」は表示しません。

## 過去日の修正

- ステータスの意味と操作は今日のチェックと同じです。
- 中止可能な習慣では中止も選べます。
- メモ欄も「やった」の日だけ編集できます。
- スペシャルチャレンジも同じモーダルから記録・解除できます。
- チャレンジの解放条件は今日のチェックと同じで、その日の基本点が100点のときだけです。
- モーダルの中で基本点を100点にすると、その場でチャレンジが解放されます。
- 保存成功後は、モーダルと背後の履歴を最新状態へ更新します。
- 過去日の修正は累計点、ごほうび、連続満点も再計算します。

## 制約

- 未来日は編集できません。
- 夏休み期間外の日は編集できません。
- 外出日も編集できます。
- モーダルを開いたまま子どもを切り替えた場合は閉じます。
- 基本点が100点未満の日と、記録がない日はチャレンジをロックします。
- チャレンジ項目が0件の場合、チャレンジ枠を表示しません。
- 夏休み期間が終わったあとも、履歴からチャレンジを修正できます。

## テスト観点

- 期間初日から最終日までの列表示
- 状態、点数、連続満点、外出表示
- 過去日が閲覧状態で開き、「なおす」で編集へ切り替わること
- 当日が編集状態で開き、「なおす」を表示しないこと
- 過去日の修正による履歴・累計点・ランクの更新
- 未来日と期間外の日の編集禁止
- 子ども切り替え時にモーダルを閉じること
- 基本点100点の過去日でチャレンジを記録・解除できること
- 基本点が100点未満の日と記録がない日でチャレンジをロックすること
- 過去日のチャレンジ表示に今日の記録が混ざらないこと
