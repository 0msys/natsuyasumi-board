# 履歴と過去日修正

## 履歴表示

夏休みの初日から最終日までを日ごと、項目ごとに表示します。

- 生活習慣と毎日の宿題の状態を記号で表示します。
- 基本点とチャレンジ込みの合計点を日ごとに表示します。
- 満点の連続日数を表示します。
- 外出日は外出名と専用表示を付けます。
- 今日より未来の日は記録操作の対象にしません。

## 過去日の確認

日付を押すとモーダルを開きます。
最初はその日の記録を閲覧表示します。
「なおす」を押すと、生活習慣と毎日の宿題を編集できます。

## 過去日の修正

- ステータスの意味と操作は今日のチェックと同じです。
- 中止可能な習慣では中止も選べます。
- メモ欄も「やった」の日だけ編集できます。
- 保存成功後は、モーダルと背後の履歴を最新状態へ更新します。
- 過去日の修正は累計点、ごほうび、連続満点も再計算します。

## 制約

- 未来日は編集できません。
- 夏休み期間外の日は編集できません。
- 外出日も編集できます。
- モーダルを開いたまま子どもを切り替えた場合は閉じます。

## テスト観点

- 期間初日から最終日までの列表示
- 状態、点数、連続満点、外出表示
- 閲覧状態から編集状態への切り替え
- 過去日の修正による履歴・累計点・ランクの更新
- 未来日と期間外の日の編集禁止
- 子ども切り替え時にモーダルを閉じること
