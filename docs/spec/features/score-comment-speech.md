# 採点・コメント・音声

## 今日の点数

生活習慣と毎日の宿題から基本点を計算します。
スペシャルチャレンジの点は基本点とは分けて加算します。
詳細な計算は[採点とランク](../common/scoring.md)を参照してください。

## がんばりコメント

- 夏休み期間内だけ表示します。
- 当日の点数に応じた決定的な文言を表示します。
- 学年に合わせた口調と漢字表記を使います。
- 未記入の項目や達成状況も画面上の内訳に反映します。

## 今日やること

音声を利用できる場合だけ操作を表示します。
押すと内容を文字で表示し、同じ内容を読み上げます。
今日の未記入項目と、期限の近い未完了項目を生活習慣、毎日の宿題、一回もの、選択宿題、新学期準備から組み立てます。
「やらなかった」は記録済みとして一覧から除きます。
一回ものと選択宿題は夏休み終了の7日前から対象にします。
選択宿題は、完了した選択肢がないグループを追加します。
新学期準備は期限の3日前から対象にします。
外出日は責める文言を避けます。

## 音声読み上げ

Docker 版で VOICEVOX を利用できる場合だけ、読み上げボタンを表示します。

- コメントの読み上げ（ボタン操作）
- 「きょうやること」の読み上げ（ボタン操作）
- ランク到達メッセージの読み上げ（ランク上昇の検知による自動再生）

子どもごとの話者設定を優先します。未設定の場合と、定義を読めない場合は既定話者を使います。

設定の話者を別の話者へ落とすのは、話者一覧を取得できて、そこに居ないと分かった場合だけです。
落とし先はまず既定話者、既定話者も一覧に居なければ一覧の先頭の話者です。
話者一覧を取得できなかった場合は設定の話者をそのまま使います。その話者が実在しなければ合成は400で失敗します。一覧が引けなかっただけで設定を無視すると、別人の声で読み上げてしまうためです。
管理画面の試し聞きで話者を直接指定した場合は、実在検査をせずそのまま使います。
読み上げ生成中に子どもを切り替えた場合は、古い子どもの音声を再生しません。

ボタン操作の読み上げが失敗した場合はエラーを表示します（6秒で消えます）。
ランク到達の自動読み上げが失敗した場合はエラーを表示しません。演出はそのまま出し、読み上げの声だけが出ません。自動再生はブラウザに拒否されうるためです。

lite 版では読み上げ機能を表示しません。

## 演出

- 基本点が100点未満から100点へ変わったときに、満点の花火を表示します。
- 初回表示や、すでに100点の状態で再読込した場合は表示しません。
- チャレンジが設定され、合計点が100点を超えるその日の上限へ達したときにファンファーレを鳴らします。
- チャレンジがなく上限が100点の場合は、ファンファーレを鳴らしません。
- 到達ランクが上がったときに、ランク到達の花火とメッセージを表示します。
- 3つの演出は、自分の操作の直後だけでなく、60秒更新で他の端末の記録を受け取ったときにも発火します。
- 過去日修正によるランク低下では演出しません。
- 満点とランク到達が同時なら、満点演出の終了後にランク演出を表示します。
- 演出の効果音は、その端末で音を解放したあとに鳴ります。解放前は画面の演出だけを出します。
- 音を解放するのは、チェックかチャレンジを「やった・できた」へ変えた操作だけです。「やらなかった」「中止」や、「やった」の取り消しでは解放しません。

## 更新

画面は60秒ごとに状態を再取得します。
自動更新で通信に失敗した場合は前回表示を保ち、次回更新を待ちます。

## テスト観点

- 点数帯ごとのコメントと内訳
- 未達成項目と期限前の「今日やること」への追加
- 完了した選択肢がないグループだけを終了前7日間に追加すること
- VOICEVOX の有無によるボタン表示
- 子どもごとの話者と、一覧に居ない話者の代替
- 話者一覧を取得できない場合は代替せず、設定の話者をそのまま使うこと
- 既定話者も一覧に居ない場合に先頭の話者へ落とすこと
- 読み上げ中の子ども切り替え
- ボタン操作の読み上げ失敗ではエラーを表示し、ランク到達の自動読み上げ失敗では表示しないこと
- 音を解放する前は効果音が鳴らず、画面の演出だけが出ること
- 「やらなかった」「中止」だけを操作した端末では、あとの演出も効果音が鳴らないこと
- 初回表示では満点・ランク演出を出さないこと
- 100点への遷移、チャレンジ設定時の最大点への遷移、ランク上昇だけで演出すること
- チャレンジ未設定時は100点でファンファーレを鳴らさないこと
- 満点とランク到達が同時の演出順
- 60秒更新で受け取った他端末の記録でも演出が発火すること
- ポーリング失敗時に前回表示を維持すること
