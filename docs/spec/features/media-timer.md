# テレビタイマー

## 概要

当日のテレビやゲームの利用時間を計測します。
採点とは独立した機能です。

## 表示

- 夏休み期間内だけ、子どもページ上部に現在時間を表示します。
- 押すと操作用オーバーレイを開きます。
- 設定した上限と、上限超過の状態を表示します。

## 操作

- 「みはじめた」で開始または再開します。
- 「やめた」で一時停止します。
- 開始中は、取得した経過時間へ端末時刻とサーバ時刻の差を加えて表示します。
- リセット操作はありません。日本時間の日付が変わると自動で0から始まります。

## 同期

Docker 版ではサーバ時刻を基準にします。
5秒ごとに状態を取得し、複数端末の開始・停止を共有します。
表示は端末時計のずれを補正しません。
端末時計が進んでいると経過時間を多く表示し、遅れていると少なく表示します。負の表示は0秒にします。

開始中に再度開始しても区間を増やしません。
停止中に再度停止しても時間を二重加算しません。

lite 版では同じ操作を端末内で処理し、別端末とは同期しません。

## 制約・エラー

- 上限は子どもごとに分単位で設定します。未設定時は120分です。
- 経過時間が上限と同じ秒数に達した時点から警告表示にします。
- 警告表示になっても、計測や他機能は停止しません。
- 状態取得に失敗した場合は直前の表示を保ち、オーバーレイ内に取得エラーを表示します。
- 開始・停止に失敗した場合も、状態を変えずにオーバーレイ内へそれぞれのエラーを表示します。
- 取得・開始・停止のエラーは、次のタイマー通信が成功するまで表示します。子どもページの記録操作や音声読み上げのように6秒では消えません。
- 子どもを切り替えると、前の子どもの購読を終了して新しい子どもを取得します。切り替え時にタイマーのエラーも消します。

## テスト観点

- 開始、停止、再開による累計時間
- 開始と停止の二重操作が冪等であること
- 日本時間の日付変更で0へ切り替わること
- 上限の直前は通常表示で、同値と超過は警告表示になること
- 端末時計が進んだ場合の加算と、遅れた場合の0秒補正
- 複数端末の操作を5秒ポーリングで反映すること
- 5秒ポーリング失敗時に直前の状態と取得エラーを表示すること
- 開始・停止失敗時に状態を変えず、オーバーレイ内へエラーを表示すること
- タイマーのエラーが6秒では消えず、次の通信成功で消えること
- 子ども切り替え時に前の購読を破棄すること
