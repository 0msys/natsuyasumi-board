# テレビタイマー

## 概要

当日のテレビやゲームの利用時間を計測します。
採点とは独立した機能です。

## 表示

- 夏休み期間内だけ、子どもページ上部に現在時間を表示します。
- 押すと操作用オーバーレイを開きます。
- 設定した上限と、上限超過の状態を表示します。

## 操作

- 「みはじめた」で開始または再開します。
- 「やめた」で一時停止します。
- 開始中は経過時間を端末上で補間表示します。
- リセット操作はありません。日本時間の日付が変わると自動で0から始まります。

## 同期

Docker 版ではサーバ時刻を基準にします。
5秒ごとに状態を取得し、複数端末の開始・停止を共有します。
端末時計のずれはサーバ時刻との差で補正します。

開始中に再度開始しても区間を増やしません。
停止中に再度停止しても時間を二重加算しません。

lite 版では同じ操作を端末内で処理し、別端末とは同期しません。

## 制約・エラー

- 上限は子どもごとに分単位で設定します。未設定時は120分です。
- 上限超過は警告表示だけで、計測や他機能を停止しません。
- 状態取得に失敗した場合は直前の表示を保ちます。
- 子どもを切り替えると、前の子どもの購読を終了して新しい子どもを取得します。

## テスト観点

- 開始、停止、再開による累計時間
- 開始と停止の二重操作が冪等であること
- 日本時間の日付変更で0へ切り替わること
- 上限の直前、同値、超過
- サーバ時刻と端末時計がずれた場合の表示
- 複数端末の操作を5秒ポーリングで反映すること
- 子ども切り替え時に前の購読を破棄すること
