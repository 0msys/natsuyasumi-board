# 日次チェック

## 概要

今日の生活習慣と毎日の宿題を、項目ごとに記録します。
記録日は、画面が最後に取得した日本時間の当日です。
画面は60秒ごとに日付を更新するため、日付変更後から次の更新までは前日へ記録します。

## 表示条件

- 夏休み期間内だけ表示します。
- 「はじめとおわりだけ」の習慣は、期間の最初と最後の設定日数だけ表示します。
- 外出日でも入力できます。外出案内は表示しますが、入力を禁止しません。

## ステータス

| 値 | 画面の意味 |
|---|---|
| `done` | やった |
| `not_done` | やらなかった |
| `cancelled` | 中止。中止可能な生活習慣だけ |
| `null` | 未記入 |

同じボタンをもう一度押すと未記入へ戻します。
中止は採点上「やった」と同じ扱いです。

## 宿題メモ

宿題にメモ欄が設定されている場合だけ表示します。

- 文字列: 本の題名などを入力します。
- 選択肢: ボタンで1つを選び、同じ選択肢で解除します。
- 時間: 分と秒を別々に入力します。分は0〜99、秒は0〜59に収め、合計秒数として保存します。
- キーが `seconds` の時間欄はストップウォッチでも計測できます。

メモは「やった」の日のみ保存できます。
空値はそのメモ項目を削除します。

## ストップウォッチ

- 開始後は経過秒数を画面内で計測します。
- 時間のメモ欄が1つでもある宿題に表示します。
- 停止時に宿題を「やった」にしてから、固定キー `seconds` のメモへ秒数を保存します。
- `seconds` 以外の時間欄だけがある場合、完了状態は保存されますが、時間の保存はエラーになり、その欄は空のままです。
- 日付は停止処理の開始時に固定し、処理中の日またぎで分割しません。

## 更新結果

書き込み成功後は画面状態を全件再取得します。
点数、コメント、進捗、履歴、ごほうびも同時に更新されます。
失敗した場合は直前の画面状態を保ち、エラーを表示します。

## 制約・エラー

- 未来日と夏休み期間外の日は更新できません。
- 定義にない項目は更新できません。
- `cancelled` は中止可能な項目以外には設定できません。
- 子どもの切り替え中に返った古い応答は、新しい子どもの画面へ反映しません。

## 版の違い

操作と採点結果は両版で同じです。
Docker 版はサーバへ保存し、lite 版は現在の端末の IndexedDB へ保存します。

## テスト観点

- 4ステータスの設定と、同じボタンによる未記入への復帰
- 中止不可項目で中止を拒否すること
- 表示期間を限定した習慣の境界日
- 日本時間の日付変更から次の60秒更新までは前日へ記録すること
- 「やった」以外の日にメモを拒否すること
- 空のメモが削除されること
- 時間欄の分・秒の上限と、合計秒数への変換
- `seconds` 欄のストップウォッチ停止時に完了と秒数が保存されること
- `seconds` 以外の時間欄では、停止時に完了だけが保存され、時間の保存エラーを表示すること
- 書き込み失敗時に表示中の値を壊さないこと
- 子ども切り替えをまたぐ応答を破棄すること
