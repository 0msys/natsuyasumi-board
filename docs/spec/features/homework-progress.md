# 宿題進捗

## 一回ものの宿題

夏休み中に一度だけ行う宿題を表示します。

- 完了型は、ボタンで未完了と完了を切り替えます。
- 冊数型は、増減ボタンで0から99の値を設定します。
- 冊数型は設定した目標以上で完了です。
- 「やる・やらない」を選ぶ項目は、判断後だけ完了操作を表示します。
- 「やらない」にした項目は完了操作できません。

## 選択宿題

グループ内から必要数以上を選ぶ宿題です。

- 各選択肢を「やる」「やらない」「未定」にできます。
- 「やる」にした選択肢は完了を切り替えられます。
- グループの必要数を満たせなくなる「やらない」は拒否します。
- 選択状況と完了数を進捗へ反映します。

## 毎日の宿題

期間中の達成日数を項目ごとに表示します。
当日の操作は[日次チェック](daily-checks.md)で行います。

## 新学期の準備

- 準備項目ごとに未完了と完了を切り替えます。
- 任意項目も同じ操作ですが、必須の達成判定には含めません。
- 夏休み期間外でも表示・更新できます。

## 年度とキー

一回もの、選択宿題、新学期準備の記録は項目キーに結び付きます。
来年度コピーでは新しいキーを採番し、前年の完了状態を引き継ぎません。

## テスト観点

- 完了型の切り替え
- 冊数の0未満と99超過の補正、目標境界
- 「やらない」項目で完了操作できないこと
- 選択グループの最低必要数を割る判断を拒否すること
- 任意の新学期項目を必須達成判定から除くこと
- 来年度コピーで前年の完了を引き継がないこと
