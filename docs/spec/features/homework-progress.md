# 宿題進捗

## 一回ものの宿題

夏休み中に一度だけ行う宿題を表示します。

- 完了型は、ボタンで未完了と完了を切り替えます。「やらない」の記録が残っている間は無効です。
- 冊数型は、増減ボタンで0から99の値を設定します。
- 冊数型は設定した目標以上で完了です。
- 任意の完了型には「やる・やらない」と完了操作を表示します。
- 未判断と「やる」では完了操作ができ、「やらない」の間だけ無効にします。
- 「かならずやる」の完了型には「やる・やらない」を表示しません。
- 任意の冊数型には「やる・やらない」を表示せず、増減操作だけを表示します。

### やらないを残したまま必須へ変えた場合

判断は記録側に残り、定義を保存しても消えません。
任意の完了型を「やらない」にしたあとで「かならずやる」へ変えると、その項目は操作できなくなります。

- 「やる・やらない」は表示されず、完了操作は「やらない」のまま無効です。
- API を直接呼んでも変えられません。完了は400「さきに「やる」に もどしてね」、判断変更は400「かならず やる しゅくだいだから」で拒否します。判断の取り消しも同じ拒否に含まれます。
- 戻すには、いったん「かならずやる」を外し、子どもが「やる」か未判断に戻してから、付け直します。

## 選択宿題

グループ内から必要数以上を選ぶ宿題です。

- 各選択肢を「やる」「やらない」「未定」にできます。
- 未判断または「やる」の選択肢は完了を切り替えられます。
- 「やらない」の選択肢は完了操作を無効にします。
- グループの必要数を満たせなくなる「やらない」は拒否します。
- 選択状況と完了数を進捗へ反映します。

## 毎日の宿題

期間中の達成日数を項目ごとに表示します。
当日の操作は[日次チェック](daily-checks.md)で行います。

## 新学期の準備

- 準備項目ごとに未完了と完了を切り替えます。
- 夏休み期間外でも表示・更新できます。

宿題進捗と新学期準備のカードは、対象項目が0件でも表示します。
新学期準備は「0 / 0」と表示します。

## 年度とキー

一回もの、選択宿題、新学期準備の記録は項目キーに結び付きます。
来年度コピーでは新しいキーを採番し、前年の完了状態を引き継ぎません。

## テスト観点

- 完了型の切り替え
- 冊数の0未満と99超過の補正、目標境界
- 目標数が100以上の冊数型は完了にならないこと
- 未判断の項目で完了操作できること
- 「やらない」項目で完了操作できないこと
- 「やらない」を残したまま「かならずやる」へ変えると、完了も判断変更も400で拒否されること
- 「かならずやる」を外すと判断を戻せるようになること
- 任意の冊数型に事前判断を表示しないこと
- 選択グループの最低必要数を割る判断を拒否すること
- 対象項目0件でも両カードを表示すること
- 来年度コピーで前年の完了を引き継がないこと
