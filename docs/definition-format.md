# 定義データの JSON 形式（エクスポート／インポート）

通常は管理画面から設定してください。このドキュメントは、エクスポートした JSON を
手で編集したい人・一括で流し込みたい人向けのリファレンスです。
実例は [examples/2026-はな.json](examples/2026-はな.json) を参照してください。

## 共通ルール

- 日付はすべて `"YYYY-MM-DD"` の文字列
- 表示ラベルはふりがな記法 **「漢字《よみ》」**（青空文庫式）で書けます。《》は直前の漢字の連続に付きます
  （例: `音読《おんどく》カードに書《か》く`）。`｜` で基底の開始を明示できます
- **`key` は記録の照合キーです。運用開始後に変更すると記録の履歴が切れます**（ラベルの変更は自由）。
  管理画面から追加した項目はサーバが自動採番します。インポート用 JSON では省略（`null`）可能で、
  取り込み時に採番されます
- インポートは「新規作成」です。**同じ子どもの同じ年**があるとエラーになります
  （年が違えば同じ子どもとして取り込めます＝来年ぶんの手入れ）
- 1人の子どもは**年ごとに定義を持てます**。子どもページに出るのは「今日を含むきかんの年」で、
  無ければ直近に終わった年 → これから来る年の順に選ばれます。
  管理画面は年タブで切り替えます（`?year=2027`）
- **年をまたぐと `key` は必ず別のものになります**。一回もの宿題・新学期じゅんび・えらぶ宿題の
  記録は年を持たない（`(child, item_key)` で1行）ので、キーを使い回すと去年の「できた」が
  今年にも出てしまうためです。管理画面の「来年ぶんをつくる」は必ずキーを振り直し、
  インポートは**まだ登録されている別の年とキーがぶつかるときだけ**振り直します
  （消した年を書き出しておいた JSON から登録しなおすときは、キーをそのままにして、
  のこっている記録に結び直せるようにするためです）

## トップレベル

| キー | 型 | 説明 |
|---|---|---|
| `child` | string | 子どもの名前（記録のキーにもなる） |
| `child_kana` | string | よみがな（見出し・読み上げの呼びかけに使う） |
| `year` | int | 西暦（`period.start` の年と揃える。保存時に変更はできません） |
| `grade` | string | `小1`〜`小6`。表示に使える漢字の範囲（配当表の累積）が決まる |
| `period` | object | `start` / `end` / `first_day_of_school`（start < end < 始業式） |
| `away` | array | 帰省・旅行。`{start, end, label}` |
| `card_rules` | object | 「はじめとおわりだけ」の記録欄の日数（下記。省略可） |
| `media_timer` | object | テレビタイマーの1日の上限（下記。省略可） |
| `voice` | object | 読み上げの声（VOICEVOX の話者。下記。省略可） |
| `habits` | array | 生活習慣（日次3値。下記） |
| `daily_homework` | array | 宿題（日次3値・メモ欄定義可） |
| `special_challenges` | array | スペシャルチャレンジ（`{key, label}` のみ） |
| `rewards` | array | ごほうびランク（下記） |
| `one_shot_homework` | array | 一回ものの宿題（下記） |
| `choice_homework` | array | 選択宿題グループ（下記） |
| `school_start_items` | array | 新学期じゅんび。`{key, label, due}` |

## card_rules

```json
{
  "edges_window_days": 5
}
```

- `edges_window_days`: `window: "edges"` の習慣の記録欄を出す「はじめ／おわり」の日数
  （1〜366。既定 5。`card_rules` ごと省略しても既定値で動く）。0以下にすると `edges` の項目が
  全日ひっこんで採点の分母が変わってしまうので、受け付けません

## media_timer

```json
{
  "limit_minutes": 120
}
```

- `limit_minutes`: テレビタイマー（アウトメディア視聴タイマー）の1日の上限。**分**で書きます
  （1〜1440。既定 120＝2時間。`media_timer` ごと省略しても既定値で動く）。**子どもごとに変えられます**
- 子ども画面には「◯時間◯分まで（のこり …）」と出て、超えると時間の色が変わります。表示は
  その子の学年で開かれます（小1なら「2じかん」、小2からは「2時間《じかん》」）
- タイマーは採点と独立です。上限を超えても点数は変わりません（生活習慣として点にしたいときは、
  `habits` に「テレビ・ゲームは◯時間まで」の項目を置いてください。この項目のラベルは
  `limit_minutes` を変えても自動では変わらないので、合わせるときは書きなおしてください）
- 管理画面では「せいかつ」タブの「テレビタイマー」で設定します

## voice

```json
{
  "speaker": 3,
  "label": "ずんだもん（ノーマル）"
}
```

- `speaker`: VOICEVOX の話者ID（スタイルID。0以上の整数）。**子どもごとに別のキャラクターにできます**
- `label`: 表示名のキャッシュ（管理画面が「だれの声か」を出すために使うだけ。合成には `speaker` しか使いません）
- `voice` ごと省略すると、サーバの既定（環境変数 `VOICEVOX_SPEAKER`・未設定なら 3＝ずんだもん）で読み上げます
- 話者IDは VOICEVOX ごとに違います。その VOICEVOX に無い ID を指していた場合（よその家の JSON を
  取り込んだときなど）は、黙って鳴る声へ落として読み上げます（管理画面の「きほん」タブで選び直せます）。
  落とすのは話者一覧を実際に確認できたときだけで、一覧が引けなかったときは設定どおりに読み上げます
  （VOICEVOX が一瞬詰まった隙に別人の声になる、を避けるため）

## habits / daily_homework の項目

| キー | 説明 |
|---|---|
| `key` | 記録キー（自動採番可） |
| `label` | 表示名（ふりがな記法可） |
| `window` | habits のみ。省略=毎日 / `"edges"`=はじめとおわりの n 日だけ / `"range"`=期間限定 |
| `window_start` / `window_end` | `window: "range"` のときの期間 |
| `cancelable` | true にすると「中止」を記録できる（中止の日は満点扱い。ラジオ体操など） |
| `meta` | daily_homework のみ。「やった」の日に開くメモ欄の定義（下記） |

meta フィールド: `{key, type, label, placeholder?, options?}`。
`type` は `text`（自由記述）/ `choice`（選択。`options: [{key, label}]` 必須）/ `duration`（秒で保存するタイム）。

## rewards

```json
{ "key": "c", "label": "ランクC", "avg": 80, "prize": "アイスパーティー" }
```

- `avg` は「1日の平均点の目安」。**到達点数 = avg × 期間日数** はアプリが導出します
- `avg` の昇順（小さい→大きい）で並べます。`prize` は任意

## one_shot_homework

| キー | 説明 |
|---|---|
| `required` | false にすると「やる／やらない」を選べる任意の宿題になる |
| `type` | 省略=`"flag"`（済/未）。`"count"` は数を数える型（読書冊数など） |
| `target` | `count` 型の目標数（1以上） |

## choice_homework

```json
{
  "key": "sakuhin",
  "label": "国語《こくご》か図工《ずこう》のさくひん",
  "min_required": 1,
  "options": [{ "key": "kansobun", "label": "読書《どくしょ》かんそうぶん", "category": "国語《こくご》" }]
}
```

- 「options のうち `min_required` 点以上つくる」宿題。全部を「やらない」にはできません
- 記録上のキーは `グループkey.オプションkey` のドット連結になります

## 旧形式（practice_homework）からの移行

宿題はもともと `daily_homework`（まいにち・30点）と `practice_homework`（くりかえし・20点）の
2区分でしたが、**設定する側からどちらに置くべきか判別できない**うえ、実質の差は1項目あたりの
重みだけだったので、`daily_homework` 1本（しゅくだい50点）に統合しました。

`practice_homework` を持つ古い JSON はそのまま読めます。読み込み時に項目が
`daily_homework` の後ろへ移され、`practice_homework` のキーは落ちます。**`key` は変えない**ので
過去のチェック記録は切れません。次に管理画面から保存した時点で、保存側の JSON からも消えます。

ただし点数は保存しておらず毎回計算し直すため、**過去の日の点数は新しい重みで再計算されます**
（旧くりかえしの項目を落とした日は下がり、旧まいにちの項目を落とした日は上がる方向に動きます）。
連続満点ストリークとごほうびランクの積み上げも同じだけ動きます。
